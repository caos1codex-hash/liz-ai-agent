# Contribuir a Liz

## Como contribuir

El proyecto está en fase inicial. Pronto habrá guías detalladas.

## Principios

1. **Liz nunca dice "no puedo"** — si falta una herramienta, créala
2. **Contexto bajo demanda** — nunca cargar todo en el prompt
3. **Código limpio** — Go idiomatic, bien documentado
4. **Tests** — toda nueva funcionalidad viene con tests

## Estructura de código

Lee [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md) antes de contribuir.
Ahí está toda la arquitectura, decisiones y flujos del proyecto.

## Commits

Usa formato convencional:
- `feat: agregar nueva herramienta de monitoreo`
- `fix: corregir error en compilador de auto-creacion`
- `docs: actualizar guia de configuracion`
- `refactor: mejorar selector de modelos`
